# iHome 
### Gestión y mantenimiento inteligente de espacios


iHome es un proyecto empresarial orientado a la organización, gestión y documentación de los sistemas, instalaciones y equipamientos de viviendas y oficinas.

La propuesta consiste en desarrollar una solución centralizada que permita registrar y consultar la información de cada propiedad, incluyendo las características técnicas de sus instalaciones, proveedores, documentación, necesidades de mantenimiento y recursos necesarios para realizar intervenciones.

Actualmente, esta información suele encontrarse dispersa entre facturas, correos electrónicos, manuales, documentos y contactos de proveedores, dificultando su consulta y seguimiento. Esta falta de organización puede provocar olvidos en las revisiones periódicas, retrasos en las intervenciones y dificultades para localizar la información necesaria.

Para dar respuesta a esta necesidad, iHome plantea el desarrollo de una base de datos relacional en Microsoft SQL Server que constituirá el núcleo de información de una futura aplicación.
